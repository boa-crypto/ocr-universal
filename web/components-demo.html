5. Validation de Formulaire

Validation en temps réel

Exemple avec Yup Schema

Utilisez SchemaBuilder.createTransitSchema() pour valider automatiquement les formulaires de transit maritime. 

// Importer yup
const { SchemaBuilder, FormValidator } = window.OcrComponents;

// Créer le schéma
const schema = SchemaBuilder.createTransitSchema();
const validator = new FormValidator(schema);

// Valider
const result = await validator.validate({
  ref: 'TR-2026-000001',
  client: 'Ma Compagnie',
  // ... autres champs
});

if (!result.valid) {
  console.error('Erreurs:', result.errors);
}
